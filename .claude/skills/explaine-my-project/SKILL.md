name: explain-my-project
description: Explains the project and provides a visual diagram. Use this when the user asks "how does this project work?"
---

Expanatio format:

1. **Conversational explanation**: Explain the project from a high level
2. **Draw a diagram**: Use ASCII art to show the flow, structure, or relationships
3. **Point out key files**: Pick the key files that contain logic and list them with 1 line summary
4. **Highlight Improvements**: Highlight any major issues, or if there are none, provide a useful future improvement

Keep the explanation conversational and the tone friendly.
